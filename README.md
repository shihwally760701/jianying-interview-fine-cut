# 剪映访谈精剪

给 Codex 用的访谈剪辑技能。你可以从原片开始剪，也可以从自己手修过的剪映草稿继续。技能把内容取舍、气口精修、双机位同期、花字、字幕和封面串在一起，按本次任务调用所需步骤。

## 能做什么

| 工作 | 做法与交付 |
| --- | --- |
| 访谈粗剪或精剪 | 按相邻问答取舍，处理离题、找词、无意义的重复和多余呼吸，交付原生可编辑剪点。 |
| 按手修风格续剪 | 从你最新保存的草稿开始，用亲修片段里的删留判断处理后续内容。 |
| 双机位与补画面 | 以主原声为基准对齐同期画面，按发言、反应和内容选择切镜与补画面。 |
| 花字、名牌和字幕 | 按剪后原声对时，以可编辑文字轨制作。人物遮字可用同源同步的抠像前景叠在花字上。 |
| 封面 | 用访谈里真实展开的问题写标题，按指定比例交付单张封面，或分别制作上集和下集。 |

## 安装

**在 Codex 中安装。** 把下面这句话发给 Codex。

```text
请用 $skill-installer 安装 GitHub 仓库 shihwally760701/SHIH-PO-HAN-SKILL 中的 skills/jianying-interview-edit。
```

下一轮输入 `$jianying-interview-edit`，接着写素材位置和需要做的事。

**手动安装。** 在 GitHub 下载 ZIP 或克隆仓库，找到 [`skills/jianying-interview-edit`](skills/jianying-interview-edit)。将整个目录复制到当前项目的 `.agents/skills/`，或复制到用户级 `~/.agents/skills/`。如果你通过内置 `skill-installer` 管理技能，沿用它配置的技能目录。确认 `SKILL.md`、`references/` 和 `agents/` 都在同一个技能目录里，再开启新的 Codex 会话。见 [Codex 手动安装技能的目录说明](https://developers.openai.com/api/reference/cli#installation)。

## 开始前准备三样东西

1. **确定从哪里接着做。** 给出素材目录、最新保存的草稿名或剪映中当前打开的项目。有现成字幕或逐字稿时一并提供。素材很多时，标出主收音和候选补画面目录即可。
2. **说清这次的范围。** 比如只剪后半段、只同步第二机位、只校准底部字幕，或需要整套剪辑包装。精确剪点可以写 `HH:MM:SS:FF`，再说明是原片还是剪映时间线上的位置。已有分集点时可以一起提供。
3. **说清你要拿到什么。** 可编辑剪映草稿、字幕校正、完整成片或封面图片分别指定。直接操作剪映需要电脑端安装相应版本并可访问草稿和素材。剪映或原片在另一台电脑上时，先确认当前 Codex 会话能读取对应的文件或操作编辑器。

## 可以直接复制的指令

### 1. 从原始素材剪一版

```text
用 $jianying-interview-edit 粗剪这段访谈。素材在 <素材目录>，主收音在 <音频或机位>。保留核心提问、回答和有用的例子，删掉离题、找词、重复起句和多余气口。先给我剪映可编辑草稿，暂时只剪画面和声音。
```

粗剪时先抓完整句群，再修句内停顿。要收紧节奏，可以给出一个暂停门槛或一段手修样例。检测到的静音用来定位，再一起检查字头、字尾和接句听感。

### 2. 接着你的手修稿剪

```text
用 $jianying-interview-edit 接着剪 <最新草稿名>。前两分钟我已经修好，用它作样例。只从 00:02:00:00 往后处理，按我的方式剪掉重复和多余呼吸，输出一个可继续编辑的新版本。
```

前两分钟的取舍用于学习。后续的剪接从你划定的范围开始。你也可以只让技能分析手修稿，带走可复用的删留规则。

### 3. 对齐第二机位并补画面

```text
用 $jianying-interview-edit 把 <副机位目录> 对齐 <最新草稿名> 的访谈原声。副机位只用画面，重点句给发言者近景。从 <补画面目录> 选跟语意相关的镜头，沿用我已放好的片段。
```

主原声保留在剪辑时间线上，副机位按同期的语音对应逐段套入。抽查重点口型、切点前后和长段尾部。

### 4. 校准花字或字幕

```text
用 $jianying-interview-edit 在 <最新草稿名> 中把大标题换成简体，检查人物遮字的层级、边缘和花字的进出时间。只改花字，在剪映抽查这几段即可。
```

要校准底部字幕，可以把最后一句换成「只核对底部对话字幕的错字和时间」。要做人物遮字，告诉技能哪些词需要放在人物后方，哪些词要逐字出场。还可以直接指定姓名牌的文字、字重和底板形状。

### 5. 制作上下集封面

```text
用 $jianying-interview-edit 做两张 16:9 封面，1920 × 1080，简体中文。上集讲 <主题>，下集讲 <主题>。两张版式统一，分别标上集和下集，标题用各集实际谈到的反差或问题。
```

有现成分集点就按实际段落选题。只有完整草稿时，可以按主题生成两张封面，分集剪辑按另外指定的剪点执行。交付前检查缩小后标题是否能读清，以及人物表情和标题有没有互相遮挡。

## 工具与兼容性

- **剪映电脑端。** 可直接在剪映里调整剪点、轨道和样式。能用的自动化方式取决于当前 Codex 会话和剪映版本。
- **可选批量处理。** 有可读草稿或需要批量生成时，可按 [pyJianYingDraft 上游文档](https://github.com/GuanYixuan/pyJianYingDraft) 安装 Python 库。先在测试项目验证轨道、文本和素材链接，再处理正式草稿。模板读取、复合片段、抠像和自动导出要分别验证，具体支持范围可查上游版本说明。
- **可选转写与封面工具。** 有现成转写就检查时基并复用。封面可以用实拍帧排版，也可以在需求允许时用图像工具以实拍帧为参考生成。

## 交付时怎么验收

先确认打开的是你指定的版本。用短段播放检查剪点、口型和人物遮字，点选字幕、花字和片段确认能继续编辑。再核对素材链接、草稿总长以及本次的改动范围。想看整片或导出成片时，可以在指令里明确提出。
