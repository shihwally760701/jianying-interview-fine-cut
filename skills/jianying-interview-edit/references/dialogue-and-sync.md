# 对话删留与声画对时

## 在完整句群里判断

先听相邻问答，决定这一段负责提问、解释、举例或转折。删留以意思是否完整、剪后能否自然接上为准。下面用虚构短句说明判断方式。

| 情况 | 处理方法 |
| --- | --- |
| 「嗯，那个，就是……其实有两个原因」开头一直找词 | 如果前缀没有表达信息，从完整的回答接起。 |
| 「费用很高，费用很高，所以我们又比较了几家」 | 无意义的复述可以减成一次，保留因果关系。 |
| 「平时要检查，下雨也要检查」 | 重复承担对照和强调，保留完整意思。 |
| 一口呼吸横跨两个旧片段 | 先在连续的剪后音轨听完整气口，再回原片找能保住两侧音节的边界。 |

「就是」「然后」「那个」有时负责衔接、排序或指代。试听完整句群，保住否定、条件、因果和观点归属。转写和静音检测适合定位，具体剪点结合原声和波形确认。旧切口的辅音听不清时回原片核对，必要时补回少量字头或字尾。

用户只想让你学习时，可以对照原片与用户精修稿，提取一组代表性删留判断和需要复核的听感。可用的参考稿可以复用到下一次续剪。

## 分段计算机位源时间

1. 记录每个主机位保留段使用的源文件、源入出点、剪后位置和播放速度。
2. 选择几段两台机位都录到的清楚语音，估计偏移和有效区间。例如 `主机位源时间 = 副机位源时间 + 偏移`，得到主机位源位置后要减去同一偏移才是副机位源位置。
3. 按「剪后位置 → 主机位源时间 → 副机位源时间」计算。主时间线跳接处重新核对对应关系，在同一项目帧边界接片。用多段同源语音确认是否漂移，再决定是否需要校正。同期副机位默认静音，必要的环境声可另行处理。
4. 预览副机位首尾、几处唇齿音和机位交接，并核查主原声和时长。缺少可靠对应的范围用主机位。只有数据核对时，交付说明实机核验的范围。

讲者推近后检查头顶、下巴、手势、视线空间和边框。双人景表现关系，单人景承接重要表情，空镜补足当句讲到的场景和事物。
